# StoriesLens development defaults

Use the installed `ponytail` skill in **full** mode for every coding task.

- Trace the real flow and fix the shared root cause once.
- Reuse existing helpers, browser features, and installed dependencies.
- Prefer the smallest working diff; do not add speculative abstractions or features.
- Never simplify away safety, privacy, validation, accessibility, or data-loss protection.
- Add one focused runnable check for non-trivial logic, then run only the proportionate tests.
- Keep searches and command output scoped so context and tokens are not wasted.
- Preserve unrelated user changes and keep final explanations short.
