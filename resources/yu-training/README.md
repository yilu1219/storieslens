# Yu 可审查训练知识库

此目录只接收来源、权利状态和教学用途均可核查的增量资料。

## 目录

- `sources/registry.json`：唯一来源登记表，包含采用与拒绝项。
- `sources/en/`、`sources/zh/`：稳定网页或官方文件的核查记录；不保存许可不明教材全文。
- `modules/en/`、`modules/zh/`：原创、简洁的教学模块，只提炼方法、评价维度与追问。
- `runs/`：每次训练的日期、变更、测试和人工决定事项。

## 准入规则

1. 必须记录作者或机构、原始网址、发布日期、获取日期、语言、年龄段、能力领域与可信度。
2. 只采用公共领域、明确开放许可或获得书面授权的内容。
3. 许可包含 `NC`、`ND`、禁止 AI/LLM 训练或用途不清时，不进入运行时知识库。
4. 不保存受版权保护的长篇原文；模块必须是 StoriesLens 自己编写的教学方法。
5. 来源只提供知识依据，不构成任何机构对 StoriesLens 或 Yu 的认可。
