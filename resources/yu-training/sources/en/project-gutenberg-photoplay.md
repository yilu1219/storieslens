- Authors: J. Berg Esenwein and Arthur Leeds
- Original publication: 1913; revised edition represented by the Project Gutenberg text
- Stable source: https://www.gutenberg.org/ebooks/17903
- Retrieved: 2026-09-18
- Rights: Project Gutenberg marks eBook 17903 public domain in the USA. StoriesLens stores no source prose; it keeps only independently written teaching abstractions and the source link.
- Language / ages: English; secondary and adult creators
- Credibility: historically important craft source for silent-era motion-picture authorship; valuable only for durable visual-story principles, not for contemporary production rules

## Adopted teaching ideas

- A screen story must communicate key meaning through observable action rather than depending on explanatory prose.
- Each scene should have a visible change: a choice, discovery, reversal, arrival, loss, or new obstacle.
- A creator can test whether a scene is filmable by separating what a viewer can see or hear from what exists only in narration.
- The smallest useful screen unit is not “more spectacle,” but one purposeful action that changes what happens next.

## Modernization boundary

The source describes silent-film conventions and an early commercial production system. Yu must not teach its obsolete formatting, gender assumptions, market rules, censorship expectations, or production constraints as current practice. The module is a modern, original abstraction centered on visible action, scene change, and creator intent.
